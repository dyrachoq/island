# Island — Dynamic Island для Windows 11

Rust + Tauri 2, фронт на чистом HTML/CSS/JS (без npm).

## Что уже есть
- Чёрный «остров» сверху по центру экрана, пружинные анимации морфинга
- Раскрытие при наведении или по клику (переключается в настройках)
- Клики сквозь прозрачную часть окна — остров не мешает работать
- Музыка: обложка, трек, прогресс с перемоткой, play/pause/next/prev для любого плеера (Spotify, Яндекс Музыка, YouTube в браузере, AIMP…). Эквалайзер красится в цвет обложки
- Буфер обмена: история текста и картинок, закрепление, удаление, клик копирует обратно. Пароли из менеджеров паролей пропускаются
- Полка файлов: перетащи файлы на остров — лежат там (ссылками), вытаскиваются обратно в любое окно, двойной клик открывает
- Громкость и яркость: индикатор на острове при изменении, громкость колесом мыши над островом. Системный индикатор Windows можно прятать (настройка)
- Значки файлов на полке как в Проводнике (с миниатюрами) или простые цветные — на выбор в настройках
- Таймер и секундомер, в свёрнутом виде показываются как «живая активность»
- Уведомление об окончании таймера со звуком
- Анимация при подключении зарядки, уровень батареи в раскрытом виде
- Автоскрытие в играх и полноэкранном видео
- Иконка в трее, окно настроек, автозапуск с Windows, защита от второго запуска

## Что понадобится
1. Rust (MSVC): https://rustup.rs — при установке поставь «Desktop development with C++» из Visual Studio Build Tools
2. Tauri CLI: `cargo install tauri-cli --version "^2" --locked`
3. WebView2 в Windows 11 уже есть

## Запуск
```
cargo tauri dev
```
Первая сборка долгая (несколько минут), потом быстро.

## Сборка через GitHub (если не хочется ставить Rust)
1. Создай репозиторий на GitHub и залей туда проект.
2. Открой вкладку **Actions** — сборка запустится сама.
3. Если шаг `cargo check` красный — открой его и скопируй ошибки.
4. Если всё зелёное — внизу страницы сборки будет архив **Island-setup** с установщиком,
   а **ui-screenshots** — скриншоты всех состояний острова из тестов.

## Сборка установщика
```
cargo tauri build
```
Установщик появится в `src-tauri/target/release/bundle/nsis/`.

## Где что
- `src-tauri/src/main.rs` — окна, трей, команды, фоновые потоки
- `src-tauri/src/media.rs` — плеер через Windows Media Controls (SMTC)
- `src-tauri/src/clipboard.rs` — история буфера обмена
- `src-tauri/src/shelf.rs` — полка файлов
- `src-tauri/src/audio.rs` — громкость (Core Audio) и яркость (WMI)
- `src-tauri/src/sys.rs` — WinAPI: курсор, батарея, полноэкранный режим
- `src-tauri/src/settings.rs` — настройки (хранятся в `%APPDATA%\com.malenkov.island\settings.json`)
- `src/island.*` — сам остров
- `src/settings.*` — окно настроек

## Тесты интерфейса
Интерфейс проверяется в headless Chromium (тот же движок, что WebView2) с подменённой Rust-частью:
```
pip install playwright pillow
playwright install chromium
python tests/test_ui.py
```
Скриншоты всех состояний сохраняются в `tests/shots/`.

## Известные ограничения
- Скрытие системного индикатора громкости — неофициальный способ (как в ModernFlyouts/HideVolumeOSD). В самый первый раз после запуска он может мелькнуть на долю секунды. Если Island завершится аварийно, индикатор вернётся после перезапуска Проводника.
- Яркость видна только для встроенного экрана ноутбука; внешние мониторы через WMI её не отдают.
- Полка хранит ссылки на файлы. Если файл переместить, плитка станет «Не найден».
